## Validation snapshot

The focused Vulkan-enabled build passed CTest on the available llvmpipe Vulkan CPU implementation, including valid/malformed GGUF and SafeTensors fixtures, indexed model descriptors, exact native GGUF Q4_0/Q8_0/Q4_K payload bounds, model-bound lazy caller-buffer Q4_K/Q8_0 execution, file-span bounds, the narrow dense graph-plan fixture, the tiny decoder golden-logit fixture, explicit Mixtral mapping, selected-expert F32 and native Q4_K CPU MLP fixtures, the MoE oracle, quantized tensor contracts, generic scalar/DP4/Q4_K/Q8_0 dispatch, and native Q4_K Vulkan/CPU differential dot and one-command multi-row matvec fixtures plus native Q8_0 dot. All generated shader modules contained compute entry points. A fresh clean no-Vulkan build remains required after the Q8_0 slice and must pass using named stubs. Discrete-GPU behavior/performance remains unvalidated; the implementation still has no full transformer execution or generation path. Cooperative matrices remain absent from implementation paths.
